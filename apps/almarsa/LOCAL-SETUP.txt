AL MARSA — RUN LOCALLY
======================
From inside the "almarsah restaurant" folder:

1. Copy .env.example to .env, then set ALMARSA_ADMIN_PASSWORD to your own secret
   password (at least 12 characters). Do NOT include .env in shared ZIPs.
2. Open terminal 1: node --env-file=.env server.mjs
   Admin: http://localhost:3000/admin.html
3. Open terminal 2: npm install (first run only), then npm run dev
   Customer menu: http://localhost:5174/
4. For a production-style local test: npm run build; then run the backend
   and visit http://localhost:3000/ for the built customer menu.

The development server proxies /api and /uploads to port 3000.
New visible categories and dishes saved in the admin should now show on the
customer menu after a page refresh. Admin "Customer menu" links open 5174
in local development, or the same origin in production.

If port 3000 is already in use, stop the existing Al Marsa backend before
starting another. If port 5174 is in use, stop the older Vite process.
